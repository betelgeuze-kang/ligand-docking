# Pre-merge Checklist

- [ ] Task spec, work queue, or issue is linked.
- [ ] Acceptance criteria are satisfied.
- [ ] Required tests are added or updated.
- [ ] `./scripts/ai-verify.sh` passed.

- [ ] Rollback plan exists for R2+ changes.
- [ ] No CASP submission, deployment, publication, or external mutation occurred without human approval.
