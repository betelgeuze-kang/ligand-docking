# P1: 설치된 CLI의 실제 준비 입력 완주 — 2026-10-18

이 문서는 최초 `15c01c8bd` 패키지의 실행 기록이다. 이후 hosted CI가 엔진의
제품 import를 거절해 진입점을 제품 wrapper로 옮겼다. 이 기록의 소스·숫자·해시를
수정 패키지의 실행 결과로 재표기하지 않는다.
[수정본 검증](docking_priority_p1_corrected_install_20261018.ko.md)은 별도 기록했다.

새 CPU 환경과 저장소 밖 작업 디렉터리에서 **SRO 26원자 / 고정 수용체
4,376원자 한 사례**를 실행했다. 입력 검사 → B0 원래 상태 관측 → B3 1단계
후 알려진 체크포인트 → 검증·보고 → 한 번 재개 → 검증·보고까지 완료했다.
완료 결과의 재개 요청은 추가 수치 계산 없이 기존 결과를 돌려줬다.

이는 좁은 설치·실행 경로의 개발 증거다. 수치 수렴, 화학적 타당성,
결정 포즈 정확도, 일반 도킹·성능·고객 승인은 별도이며 미충족/미검증이다.
새 물 모델이나 8DOF 연구 실행기를 이 사례에 통합한 결과가 아니다.
원시 입력을 공개 배포한 독립 재현 패키지도 이 기록의 범위에 포함하지 않는다.

이어 새 CPU 환경에 의존성을 설치했으며 실제 계산은 이 환경에서만 수행했다.

## 실제 계산 결과와 비용

모델은 기존 명시적 Fourier 고정 수용체 프로파일이다. 원래 입력 5개 참조와
출처 파일 6개를 그대로 검증해 사용하고, 과거 40단계 프로토콜은 재개하거나
수정하지 않았다. 새 프로토콜·실행 디렉터리·현재 소스 결박을 별도로 만들었다.

| 항목 | 원래 B0 | 마지막 관측 B3 |
|---|---:|---:|
| 전체 모델 에너지 (kcal/mol) | 14.798201989215876 | -6.265237047193981 |
| 리간드 내부 에너지 (kcal/mol) | 38.73121629302294 | 28.24290538778814 |
| 원시 최대 원자힘 (kcal/mol/Å) | 128.4364735627077 | 19.902898756321665 |

전체 모델 에너지 차이는 -21.063439036409857 kcal/mol이다. 에너지 감소를
친화도나 더 정확한 포즈의 증거로 판정하지 않았다. RMSD·전체 화학적 타당성은
평가하지 않았고 보고서에 `null`이다. 포즈 채택은 `false`다.

- 수락 4단계 후 `max_iterations_reached`, `numerical_convergence=false`.
  변경하지 않은 힘 기준 0.001 kcal/mol/Å에 미달했다.
- 힘 평가 **8회**: B0 1 + 첫 invocation 2 + 재개 invocation 5.
  optimizer 관측 6회와 재개 확인 1회가 포함된다. 실패한 힘 호출은 0이다.
- B3 trial 거절도 관측·비용에 남아 있다. 4개 수락 단계와 평가 횟수를 혼동하지 않는다.
- 한 번 재개할 때의 사전 상한 19회 이내다. 합성 시험의 힘 호출은 이 8회에
  포함하지 않았다. 단일 사례의 반복·재개를 독립 분자 수로 세지 않았다.
- 외부 감독기: 총 wall 600초, CPU affinity 1, 자식 주소 공간 6GiB,
  파일당 및 총 출력 512MiB. 실제 전체 감독기 wall 95.083494745초,
  자식 최대 peak RSS 491,593,728bytes, 보존 산출물 약 350KB다.
- 수치 invocation 내부 wall 합계는 16.641019924초다. 전체 감독기 시간과
  범위가 다르며 설치 시간도 포함하지 않는다. 속도 개선의 비교 실험은 아니다.
- 10개 자식 단계가 모두 exit 0. 미처리·미상 작업은 없었다. 실제 실패·강제
  중단 실험은 하지 않았으며 해당 경계는 합성 검사로 검증했다.
- verify/report 전후 및 완료 결과 재조회 전후 journal 바이트·보존 비용 동일.
  보고·검증·완료 재조회의 추가 E/F는 0이다.
- 원래 출처 바이트의 실행 전후 해시 동일. 기존 체크아웃·과거 실행을 변경하지 않았다.
