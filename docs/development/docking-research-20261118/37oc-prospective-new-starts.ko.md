# 37OC의 새 시작점에서 동결 정책 검증

새로운 강체 교란 시작점 4개에 기존 대조군과 aryl +30° 정책을 각각 적용해 8개를 제출했다. 시작점을 고른 뒤 시드, 후보 수, E/F 상한, D3 선택 정책, 최대 원자힘 0.001 기준을 고정했다. 알려진 포켓을 사용했다. 결정 리간드의 RMSD는 생성·점수·선택에 제공하지 않았다. 선택과 추천 순위를 먼저 기록하고 SHA256을 고정한 후에, 고정 수용체 좌표계에서 입체화학과 대칭을 반영해 중원자 RMSD를 측정했다.

**+30°에서 1/4, 대조군에서 0/4가 복합 조건을 충족했다.** 시드 20261118041의 +30° 후보는 원래 시작점 2.5063 Å, 배치 직후 2.2179 Å에서 최종 1.8341 Å에 도달했다. 실제 선택 좌표의 독립 CPU 재평가 최대 원자힘은 0.000954689937 kcal/mol/Å였다. 수소 접촉, 설정된 PoseBusters 구조 검사 22개와 기존 D3를 통과했다. ScorerV1의 원래 D3 순위는 3위였다. 여기에 기존 힘·품질 조건을 적용한 추천 순위에서 1위가 됐고 최종 채택됐다. 추천 목록에는 1건이 있어 Top-5에도 포함됐다.
