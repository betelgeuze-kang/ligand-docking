# 합성 샘플링 관측의 Rust 링크 실패와 재현

#628의 전체 CPU CI에서 합성 시험 두 개가 `E0463`으로 실패했다. 실패한 러너는 Rust/Cargo 1.100.0을 사용했고 직전 통과한 러너에는 1.99.1이 설치돼 있었다. Cargo 1.100이 중간 산출물 레이아웃을 변경했다. [실패 로그](https://github.com/betelgeuze-kang/ligand-docking/actions/runs/44408701465/job/135170742554) · [Cargo 변경](https://github.com/rust-lang/cargo/pull/17354)

로컬에 설치된 1.99.0에서는 기본 레이아웃의 대상 시험 7개가 통과했다. 중간 산출물 경로와 최종 산출물 경로를 분리하면 같은 `E0463`이 발생했다. 주 라이브러리의 경로는 Cargo에서 받았지만 `libm` 의존 경로는 주 라이브러리 옆의 `deps`로 추정한 것이 직접 원인이었다.

Cargo가 보고한 의존 경로를 전달하는 로컬 시안은 분리 레이아웃에서 시험 7개와 고정 영수증 3개를 통과했다. 증거 수집기가 기존 실행기 원문의 해시를 요구하기 때문에 이 시안은 기존 수집기의 소스 확인에서 거절됐다. 기존 실행기·수집기의 소스 결속을 보존하고 전체 CPU CI가 저장소의 Rust 1.93.0을 사용하도록 고정했다. 로컬 영향 범위 시험 40개와 기존 실행기·수집기 재확인 시험 19개가 각각 통과했다. 두 집합의 중복 시험을 합산하지 않았다. [CI 수정 커밋](https://github.com/betelgeuze-kang/ligand-docking/commit/9e72c5eb6b4d6849b707f52b8f8651858c7cc8b1)

합성 실행과 저장 증거 검사만 포함한다. 실제 분자 계산과 실행 자격은 이 기록의 범위 밖이다.
