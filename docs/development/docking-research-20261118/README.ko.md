## 엔진 성능 기록

- 동일 SRO 64포즈 v3b의 준비 제외 최적화 중앙값은 융합 CPU 제어+HIP U/F **1.086초**, 동일 제어 CPU 1작업자 **14.559초**, CPU 6작업자+부모 **3.190초**였다. 각각 세 표본이다. 기준은 해당 호스트의 Torch AVX2 합산 순서와 gfx1030 환경에 묶여 있다.
- 동일 토폴로지 1,024개 반복 작업의 초기 용량 지도에서 HIP 활성 256/512는 **12.165/12.107초**였고, 256이 이 실험의 잠정 기본값이었다. 후반 2,048작업은 **54.758작업/초**였으며, 느려진 구간에서 U/F보다 제어·저장·내보내기 시간이 늘었다. 원인은 미확정이다.
- 동일 토폴로지 반복과 다양한 고유 화합물 라이브러리의 실제 배치 충전율은 별개다. 이종 토폴로지 포즈를 한 U/F 호출에서 묶는 성능, 준비 포함 실라이브러리의 우위, 서비스 동시 처리 한계는 미검증이다.
