# Coordinate exchange and diagnostic boundaries

The text exporter writes GRO positions as three adjacent 15.10 fixed-width nm fields, retaining atom headers, box text, units and ten fractional digits. Existing parent admission still rejects velocity-bearing GRO input rather than deleting velocity state. PDB/SDF formatting, original inputs, parameter assignments and the binary64 array writer are unchanged. Old generated files and source-bound journals are not rewritten; use the original implementation for an old run or start a new run.

The high-precision force diagnostic retains the original analytic model, checker verdict and 1e-8 absolute tolerances. Its auxiliary energy difference uses the original central stencil when admissible and an O(h^2) forward/backward stencil at the declared minimum-distance boundary. Both requested step sizes and the method are reported. Arithmetic is performed at 120 decimal digits to avoid a rounded square root falling just below the exact binary64 minimum at the center. A smaller-step error is checked for convergence, not confused with the coarse stencil's truncation error at very large forces. No coordinates are clipped or moved in the original report.

Synthetic tests cover v1/v2/v3 export, mixed signs and integer widths, independent fixed-width parsing, optional MDAnalysis/MDTraj reading, minimum-distance neighbors, negative-axis backward differences, mixed successful/failed reports and unchanged original verdicts. The dedicated hosted workflow installs both independent readers. No external solver, source authentication, molecular validation, AI performance, GPU or MD qualification is implied.
