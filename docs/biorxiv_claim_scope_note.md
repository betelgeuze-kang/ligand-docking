# Claim Scope Note

The accepted `v7r1` package supports a strong computational claim: the architecture passes a preregistered cross-domain blind validation protocol across GPCR, ion-channel, kinase/protease, and IDP tasks under frozen evaluation rules, with an audited reviewer-facing artifact bundle.

That claim should not be expanded into a stronger experimental claim. The current package does not establish prospective wet-lab hit discovery, orthogonal biochemical confirmation, medicinal-chemistry optimization, or clinical utility. It should therefore be described as a preregistered and reviewable computational validation package rather than as an experimentally validated screening platform.

The temporal scaffold follows the same boundary. It is now strong enough to audit and extend, with `202/206` rows item-ready and the remaining `4/206` rows explicitly policy-coded, but it remains a mixed item-level and dataset-level temporal package rather than a fully completed per-row temporal generalization study. The runnable provisional temporal spec should therefore be described as a conservative scaffold, not as a finished future-only benchmark.

The same care applies to robustness language. The completed robustness battery shows that all preregistered set passes are preserved under changed randomness paths and harsher decoy pressure, which strengthens the computational claim. It does not imply that every domain or metric is numerically invariant, and it should not be paraphrased as a guarantee that all EF1 values remain in the `90s` under all validation extensions.

This note is intended to keep the manuscript and submission assets aligned around the same non-overclaim policy: strong computational validation, explicit provenance limits, and no implied wet-lab proof where none has yet been produced.
