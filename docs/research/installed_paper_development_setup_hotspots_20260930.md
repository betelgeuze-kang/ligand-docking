# Installed paper-development setup: retained timings and source hot-spot audit

This read-only audit identifies candidates for reducing metadata setup cost after the fixed PR49/PR59 campaign. It inspected source bytes and already completed stage/invocation receipts. It made no force, score, optimizer or additional real preflight calls, did not attach to or signal the live process, and changed no frozen runtime files. A sandbox `ps` lookup was not authoritative process evidence; the root session remained the execution authority.

The paired installed protocol is `94b4589c6755119ead7c4e8d91fad533fa4e70c4d4a91773e6ee80561c55b254`. The installed wheel is `e30ca2394df3b0df01e844a76af793e4176e3e6321b2232af64b86109abf55aa`. The [evidence receipt](../evidence/installed_paper_development_setup_hotspots_v1.json) pins the protocol, wheel, 17 source files, completed external preflight/pause stages and each candidate's durable first invocation start/end and binding. Every analyzed source file was compared byte-for-byte with its wheel member.

## Source-derived candidates

1. **Repeated prepared-system reconstruction and canonical identities.** [Bridge `_preparation`](../../betelgeuze_product/installed_paper_development_comparison.py#L119) calls the original registered `input_binding` at line 131, then reconstructs receptor and ligand again at line 132. [Freeze](../../betelgeuze_product/installed_paper_development_comparison.py#L181) converts the unchanged original request at line 211 and constructs a Cartesian binding at line 212. The [old registered admission](../../betelgeuze_product/cpu_refinement_v1_2/registered_policy_adapter.py#L49) delegates through `load_request` and the [original prepared loader](../../betelgeuze_product/refinement_comparison_workflow.py#L49); [Cartesian admission](../../betelgeuze_product/cpu_refinement_v1_3/workflow.py#L163) reconstructs its own systems. For one complete bridge freeze, the static path therefore has **six receptor decodes and six ligand decodes across the pair**, plus four scorer constructions. This count excludes imports and later run/resume/verify admission.

   Both adapter paths pass `_json(_bound(ref))` to the canonical system loader. [_bound](../../betelgeuze_product/reference_minimization_workflow.py#L47) already parses with duplicate/nonfinite rejection; `_json` serializes the document again; the [canonical loader](../../betelgeuze_engine_v2/molecular/serialization.py#L341) parses it, verifies the canonical payload hash and then verifies the reconstructed system hash. [Canonical hashing](../../betelgeuze_engine_v2/molecular/serialization.py#L135) recursively normalizes complete topology, coordinates, metadata and provenance. These are concrete repeated serialization/validation candidates, not redundant trust checks that may simply be deleted.

2. **Repeated full-receptor integrity and context construction.** The declared receptor has **4,376 atoms**, while each authenticated pocket/scorer subset has **974 atoms**. [FixedReceptorEnvironment](../../betelgeuze_product/cpu_refinement_v1_2/fixed_receptor.py#L130) rederives the full receptor canonical hash in `assert_intact`; construction, `validate_ligand`, evaluator construction and evaluator identity each reach this check. [Cartesian `_intact`](../../betelgeuze_product/cpu_refinement_v1_3/workflow.py#L213) also verifies original files, fixed state, authority and canonical ligand/receptor identities.

   [ExplicitGraphScorer](../../betelgeuze_product/cpu_refinement_v1_2/chemical_features.py#L255) first derives explicit chemical features, then its parent derives a complete [scorer context](../../betelgeuze_engine_v2/docking/scorer_v1.py#L927), including validation, canonical source hashes and legacy feature derivation. Constructor setup also builds receptor cells and computes reference intraligand vdW arithmetic. Those local loops cover 974 receptor cells and at most 741/903 ligand pairs for 39/43 ligand atoms; they have not been individually timed. The measured 1.70–1.75-second constructor scopes justify profiling this path, not attributing all time to one loop.

3. **Repeated source metadata and geometry checks are secondary candidates.** `_source` runs at freeze entry and inside preparation, revalidating source descriptors, article/identity evidence and canonical RDKit chemistry. The [registered pose geometry gate](../../betelgeuze_product/installed_native_v4_registered_binding.py#L475) checks the unchanged pose against the pocket and all-source receptor overlap. Its [minimum-distance calculation](../../betelgeuze_product/prepared_hard_overlap_screen.py#L31) is already vectorized in blocks of 64 receptor atoms: 170,664 pairs for PR49 and 188,168 for PR59. No retained component timer shows that this screen dominates. No geometry or chemistry gate should be dropped to reduce time.

## One next implementation, after the fixed campaign

The highest-value next work is an **opt-in installed setup profiler**, followed only if measurements support it by a versioned verified-input snapshot for parsing and canonical derivations reused within one freeze invocation. The profiler should write a separate receipt and leave current protocol/results unchanged. Use representative synthetic systems first, with public force/score/optimizer entrypoints forbidden. No repeated real preflight is authorized by this report.

Useful outer stage names are `source.validate`, `old_binding`, `parse_systems`, `params`, `fixed.validate`, `ligand_identity`, `charge`, `geometry`, `cohort`, `conversion`, `cartesian_binding` and `final_revalidate`. Lower-level counters should distinguish canonical parsing, canonical system hashing, authority construction and scorer construction. Record wall/CPU nanoseconds, calls/completed/failed, verified bytes and atom counts; preserve inclusive scope relationships so overlapping timers are not added.

A later snapshot must bind verified raw SHA, canonical path, runtime/source identity, environment, settings and ligand-specific identity. Revalidate stable source bytes at public entry/exit, retain duplicate/nonfinite rejection and both canonical-payload/reconstructed-system checks, and preserve exact coordinate, graph, charge, pocket, cohort and failure-denominator behavior. Mutable tensors require content-integrity checks; a frozen dataclass does not make its tensors immutable. Reusing an authority/scorer wholesale between original and Cartesian implementations is unsafe because their implementation identities differ. A persistent cache keyed only by path, receptor identity or DOI would also be unsafe. Any new implementation identity must be declared and tested rather than silently treated as the existing frozen route.

Validation should compare exact semantic bindings, original/converted requests, coordinate hex, geometry gates, raw and admitted arm selections, candidate/preparation-failure denominators and durable work behavior. Include source replacement, candidate swap, coordinate or tensor mutation, malformed canonical seals, duplicate/nonfinite JSON and interrupted-work cases. Keep null roles, unknown independent measurement denominator and all training/source-equivalence limits intact. Reference constructor arithmetic remains setup cost even if reused; it must not be hidden as zero total work.

No optimization was implemented or benchmarked here. There is no speedup, affinity accuracy, source-parameter equivalence, training eligibility or scientific qualification claim.
