# Wet-Lab Packets

This folder contains collaboration-ready starter artifacts for external wet-lab outreach.

## Immediate Use

- `egfr_kinase_pilot_controls.csv`
- `adrb2_gpcr_pilot_controls.csv`
- `hiv1_protease_pilot_controls.csv`
- `trpv1_ion_channel_candidate_shortlist.csv`
- `trpv1_ion_channel_sourcing_request.csv`
- `trpv1_ion_channel_normalization_notes.md`

These are the two recommended Phase 1 pilot targets because they already have:

- a clean control story
- simple assay framing
- in-repo provenance

`HIV1_PROTEASE` is now also usable as a Phase 1 or Phase 1.5 target because the disjoint control panel is already available in-repo.

`TRPV1_ION_CHANNEL_BLIND` is now identity-normalized enough for sourcing review, but it still needs vendor confirmation before it should be presented as a final assay-ready packet.

## Before Sending

- confirm compound availability with the partner or vendor
- confirm assay mode before finalizing the exact concentration scheme
- keep the first ask to 6 compounds total when possible
