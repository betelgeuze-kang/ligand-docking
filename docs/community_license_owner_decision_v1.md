# Community license owner decision record v1

No license is changed by this document.

The owner must record one explicit choice:

- MPL-2.0 native core + Apache-2.0 benchmark/verifier tools;
- Apache-2.0 core;
- AGPL-3.0 + commercial dual license;
- interim source-available evaluation license;
- remain proprietary.

Before choosing:

1. inventory first-party and third-party source, data, weights, and models;
2. decide hosted-service and proprietary-embedding policy;
3. decide CLA, DCO, assignment, or no external code acceptance;
4. separate engine, benchmark tools, enterprise service, UI, and weights;
5. review patents and pending applications;
6. add package-level LICENSE and THIRD_PARTY_NOTICES;
7. ensure the chosen license permits the intended independent build,
   benchmark, modification, patch submission, and result publication.
