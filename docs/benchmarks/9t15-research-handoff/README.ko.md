# 9T15 도킹 연구 인계

**다음 작업은 기존 포켓 안에서 경계와 평행한 탐색 방향으로 힘 수렴을 계속할 수 있는지 확인하는 것이다.** 일반 정제는 1.779 Å까지 수렴했으나 H18과 H1이 포켓 밖으로 나갔다. 포켓 밖 trial을 거절하는 기존 프로필은 1.880 Å 포즈를 보존했으나 선탐색에서 멈췄다. 2026-11-20 기준 **Top-1·Top-5 복합 통과는 0건**이다.

## 재개 순서

1. **원본 실행 상태를 확보한다.** [수치와 증거 지문](evidence.json)의 `handoff_slot`, `source`, `local_evidence`를 확인한다. 같은 호스트에서는 연구 아카이브에서 최신 캠페인 디렉터리를 찾아 `sha256sum -c SHA256SUMS`로 검사한다. 다른 호스트에서는 준비된 입력, 고정 시작점, 실제 소스 사본, 라이브러리와 런타임 결속 자료를 승인된 인계 경로에서 확보한다. 재실행 전 현재 실행 자격과 자원 조건을 확인한다.
2. **재현 대상은 슬롯 3 후보 1404다.** 로컬 `REPAIRED.json`의 `slot=3`, `void_rigid.raw_index=1404`를 사용한다. 같은 conformer의 D3 기준과 시작점 ID를 고정한다. 일반 정제 대조 자료는 `RESULT.json` 및 `{cpu,hip}-relaxed/POCKET-TRACE.json`, 정확한 포켓 선검사 자료는 `GUARD.json`이다.
3. **경계에서 trial 방향만 바꿔 짧게 시험한다.** 기존의 마지막 유효 상태와 첫 이탈 직전 상태를 참조 없이 정하고, 포켓 안쪽과 접선의 방향에서 유효한 에너지 하강이 가능한지 검사한다. 기존 거리 검사와 Armijo 수용 조건을 사용한다. 논리 trial, E/F, 사전 거절, 최대 원자힘을 별도 집계한다. 기존 경계 거절 프로필과 이전 투영 실험은 `evidence.json`에서 찾을 수 있다. 이전 실험의 결과는 해당 실험 조건에만 적용한다.
4. **짧은 점검이 통과하면 정책을 고정해 장스텝을 비교한다.** 슬롯 3부터 확인한 뒤 CPU/HIP를 동일 4슬롯에 적용한다. 기존 D3·ScorerV1과 12슬롯 분모를 유지한다. 포켓 0.500 Å, 힘 0.001 kcal/mol/Å, 슬롯당 641회 한도를 그대로 사용한다. 단기 평가와 D3 기준 평가도 예산에 포함한다. 제약 방향의 정체는 전체 원자힘 수렴과 별도 상태로 남긴다.
5. **완료 판정.** RMSD ≤2 Å, 기존 접촉·포켓·PoseBusters·D3, 힘 수렴, Top-1 및 Top-5를 각각 기록한다. RMSD는 수용체 좌표계에서 대칭 대응을 고려해 순위를 확정한 뒤 계산한다. 조건을 모두 충족하면 9T15 개발 결과로 보고하고, 동결 정책을 새 시작점과 독립 분자에서 검증한다. 이번 보정 후보는 장스텝 시작 전에 이미 2 Å 안에 있었다. 먼 포즈에서 장스텝만으로 회복한 수에는 포함하지 않는다.

## 이전 실험

- **거리장 생성.** 두 경로 각각 7,008개 중 1.970 Å 근방의 동일 배치가 반복됐다. 전체 에너지·교차 에너지·ScorerV1 선별에서 순위가 낮았다.
- **64개 대표의 짧은 완화.** 한 배치가 1.970→1.966 Å로 남았고 PB 단백질 최소거리 한 항목을 실패했다. C3–TRP81 CH2 거리는 2.142→2.287 Å였고 PB 기준은 2.550 Å였다. 이 배치의 장스텝 정제는 당시 미실행이었다.
- **PB 거리 보정.** 최초 대표 기준 총 0.30 Å로 해당 쌍을 해소하지 못했다. 짧은 완화 뒤 별도 0.30 Å의 보정에서 1.944 Å 배치가 PB·접촉·포켓을 모두 통과했다. 최초 대표부터의 최대 원자 이동은 0.539 Å였다. 두 이동 예산을 구분한다.
- **포켓 격자 정정.** 이전 2.810 Å 포즈는 확장 격자에서 유효했고, 같은 대조군의 원래 격자에서는 포켓 조건을 실패했다. 격자 변경의 효과는 별도 비교로 남긴다.
- **MWQ 1.831 Å 회복.** 한 분자·시작점·개발 시드에서 관측했으며 기존 ScorerV1에서 토션 8개 중 7위였다. 9T15 분모와 독립 검증 분모에 포함하지 않는다.
