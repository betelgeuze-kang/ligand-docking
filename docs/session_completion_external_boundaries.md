# External boundaries not executable in the chat session

The accompanying tools intentionally stop before the following evidence:

- real D1 materialization without the private or appropriately licensed
  32-case source bundle;
- Fresh-128 access or execution;
- ROCm/HIP device execution, VRAM measurements, ROCprofiler traces, or
  multi-architecture results;
- commercial Glide, GOLD, or other licensed-tool execution;
- wet-lab validation;
- production release signing or deployment;
- replacement of the proprietary license without explicit owner approval.

The tools create strict adapters, profiles, and verifiers so those external
steps can be performed later without weakening denominators or claim
boundaries. None of these documents or tools substitutes for the missing
external evidence.
