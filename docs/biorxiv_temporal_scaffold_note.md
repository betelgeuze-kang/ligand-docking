# Temporal Scaffold Note

The temporal scaffold is intentionally reported as a mixed item-level and dataset-level package rather than as a completed item-level temporal generalization claim. At the current freeze point, all ligand rows are item-level ready (`186/186`), while the IDP domain is split into `16/20` item-ready rows and `4/20` dataset-ready rows. The remaining dataset-ready IDP rows are not treated as an undifferentiated missing tail. Instead, they are policy-coded into three explicit categories: no safe public anchor found (`ash1_idr_fragment`, `eaf1_idr`), fragment-anchor mismatch (`tau_2n4r_fragment`), and intentional dataset-level synthetic control (`prion_like_polyq_control`).

This matters for review because the residual temporal gap is now interpretable rather than opaque. The current bundle therefore supports a reviewer-facing statement that the temporal scaffold is already strong enough to audit, reproduce, and extend, while still stopping short of overclaiming full item-level temporal provenance for every IDP holdout. In particular, the runnable provisional temporal spec should be described as a mixed-governance scaffold and not as a completed “true temporal split” benchmark. The authoritative state of this scaffold is frozen in `runs/biorxiv_temporal_submission_baseline_current.md`, with row-level policy details in `runs/biorxiv_temporal_idp_remaining_policy_current.md` and synthetic-only progress tracked in `runs/biorxiv_temporal_idp_synthetic_progress_current.md`.
